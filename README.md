## About

I build clean, fast, accessible interfaces — and I care about what happens after launch: bundle size, Core Web Vitals, and code the next developer can actually read.

Over the past **4+ years** I've shipped across three fairly different worlds:

- **ERP / SAP Business One** — front-ends for implementations where the data model is unforgiving and correctness matters more than flourish
- **E-commerce** — catalogs, carts and checkout flows, with a focus on conversion and page speed
- **EdTech** — learning and administration platforms used daily by students and staff

Currently deepening: **React Native**, **Next.js App Router**, and **Svelte**.
